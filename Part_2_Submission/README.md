# CampusConnect — Interaction Design POE Part 2

This folder contains the CampusConnect website prototype and Part 2 implementation documentation.

## Contents
- `reports/Part_2_Prototype_Implementation_Report.md` — readable report source, including the implementation discussion, testing summary and Harvard Anglia-style references.
- `prototype/index.html` — semantic page structure and sample content.
- `prototype/style.css` — responsive styling, focus styles and presentation preferences.
- `prototype/app.js` — navigation, filters, join/RSVP actions, task state and accessibility preferences.
- `evidence/test_results.txt` and `evidence/test_results.json` — scripted smoke-test record.
- `qa/run_prototype_tests.py` — Playwright test script.

## Run the prototype
1. Download or clone this repository.
2. Open `Part_2_Submission/prototype/index.html` in a modern browser.
3. Use the navigation, study-group filters, event RSVP controls, resource search, My Plan, emotional check-in and Accessibility dialog.

The prototype needs no backend or build step. Sample student groups, events and resources are illustrative. State resets when the page reloads, and resource actions are demonstration actions.

## Testing scope
The recorded results document functional smoke tests only. They are not a participant usability study or a formal WCAG conformance audit.
