# RaceDay Part 1 Documentation

This folder contains the planning and database artefacts required for Part 1.

- `RaceDay_ERD.png` – full relational ERD.
- `RaceDay_ERD.pdf` – PDF copy of the ERD.
- `raceday-endpoint-plan.md` – REST API endpoint specification.
- `RaceDayDB.sql` – SQL Server database creation and seed script.
- `commit-plan-part1.md` – suggested meaningful commit sequence.

The ERD and SQL script were designed together so that primary keys, foreign keys, uniqueness constraints and cardinality remain consistent.
